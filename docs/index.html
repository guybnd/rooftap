  • Tiles deep-link. The budget tile opens Costs, the grocery tile opens the list.
  • Per-user layout. The phone's toggles hide and show this screen's modules, per account.

Tasks

Recurring tasks and reminders with assignees, comment threads, and nested checklists.

  • Recurrence. Repeat every N days; completed instances regenerate on schedule.
  • Gestures. Swipe right completes; swipe left snoozes for an hour, a day, or a week.
  • Nested detail. Checklists and comment threads attach to the task record itself.
  • Generated reminders. Document expiry and contract end dates materialize here as reminder rows.

  • Per-event visibility. A private flag keeps an event off the shared grid.

The capture button is available on every screen and routes input by type.

  • Quick-add. A cost, to-do, event, grocery item, or listing URL from any screen, in two taps.
  • Photo routing. An invoice becomes a cost item with the file attached; a receipt attaches to the open shopping session and is OCR-parsed.
  • Global search. Fuzzy search across all sections, opening the item's editor directly.
  • Share target. URLs and files shared from other apps route to the matching section.

First boot generates the JWT and API keys into your .env, applies every database migration, and brings the whole stack up at localhost:3000.

The whole backend is one compose file.

A trimmed Supabase stack: Postgres 17, GoTrue auth, PostgREST, Realtime, Storage, and edge functions behind a Kong gateway.

  • No external services. Auth is your own GoTrue instance with email autoconfirm; no SMTP required, nothing phones home.
  • Automated provisioning. JWT and API keys generate into .env on first boot and are reused after; migrations apply on every start.
  • Optional integrations. A Mapbox token is required for maps; AI listing and receipt parsing, Google Calendar, and web push are opt-in and degrade gracefully.

Bring your own agent.

The app exposes an MCP server at /api/mcp: 4 read tools and 13 mutating tools over tasks, groceries, costs, and calendar. Auth is a bearer personal access token issued in settings; any MCP client works.

Group-scopedEvery call resolves to the token's user and household; the same row-level security as the app applies.
